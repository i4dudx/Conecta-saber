# Conecta Saber

Portal educativo sobre segurança digital e prevenção de golpes. O site explica os golpes mais comuns (Pix, WhatsApp, phishing, falsa central, compras, emprego, investimentos e outros), ensina boas práticas de proteção, traz um guia do que fazer se o golpe já aconteceu, um glossário de termos e uma simulação interativa para testar se você reconhece uma mensagem falsa.

Projeto acadêmico, feito com HTML, CSS e JavaScript puros, sem frameworks. É responsivo e acessível (navegação por teclado, leitores de tela e opção de reduzir movimento).

## Páginas
- Início
- Conheça os golpes (e uma página para cada golpe)
- Proteja-se
- Simulação
- Guia de emergência
- Glossário
- Contato

## Como abrir
Basta abrir o arquivo `index.html` no navegador.
